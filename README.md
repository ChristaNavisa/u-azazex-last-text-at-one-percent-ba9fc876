A make.fun bounty entry: the last text message a dying phone sends at one
percent battery, in the phone's own voice. The phone confesses two things on
its way out — that it read every group chat message and chose not to reply,
and that the cracked screen was its owner's fault.

## Run

```sh
node main.ts
```

Writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
under 200 characters.
